# 폴더 동기화 프로그램 (SSD → D드라이브)

버튼 하나로 **여러 폴더 쌍**을 한꺼번에 동기화하는 데스크톱 프로그램입니다.
Python 표준 라이브러리(tkinter)만 사용하므로 추가 설치 없이 동작하고, 원하면 단일
`.exe` 파일로 빌드할 수도 있습니다.

## 동작 방식

| 상황 | 동작 |
|------|------|
| 원본·대상 파일이 동일 (크기 + 수정시간 일치) | **건너뛰기** |
| 원본에만 있는 파일 | **복사 (추가)** |
| 양쪽에 있으나 내용이 다른 파일 | **덮어쓰기 (변경)** |
| 원본에서 삭제되어 대상에만 남은 파일 | **삭제 (사용자에게 확인 후)** |

> 각 폴더 쌍은 단방향 동기화입니다. 원본의 상태를 대상에 그대로 반영합니다.

## 실행 방법 (둘 중 하나)

### 방법 A. Python 으로 바로 실행
1. https://www.python.org/downloads/ 에서 Python 설치 (설치 시 **"Add Python to PATH"** 체크)
2. `동기화_실행.bat` 더블클릭 (또는 `python sync_app.py`)

### 방법 B. 단일 .exe 로 만들어서 실행 (Python 없이 배포 가능)
1. `build_exe.bat` 더블클릭 → PyInstaller가 자동 설치되고 빌드됩니다.
2. 완료되면 `dist\폴더동기화.exe` 가 생성됩니다. 이 파일만 있으면
   Python이 없는 PC에서도 더블클릭으로 실행됩니다.

   직접 명령으로 빌드하려면:
   ```
   pip install pyinstaller
   pyinstaller --onefile --windowed --name "폴더동기화" sync_app.py
   ```
   - `--onefile` : 하나의 exe로 묶기
   - `--windowed` : 검은 콘솔 창 없이 GUI만 표시

   > exe 빌드는 **Windows에서 직접** 하셔야 Windows용 exe가 나옵니다.

## 사용 방법

1. **폴더 쌍 추가** 버튼 → 원본(SSD) 폴더 선택 → 대상(D드라이브) 폴더 선택.
   필요한 만큼 여러 쌍을 추가합니다. (목록에서 선택 후 **수정/제거**도 가능)
2. (권장) **미리보기** 버튼으로 어떤 파일이 추가/변경/삭제될지 먼저 확인합니다.
3. **전체 동기화 시작** 버튼을 누르면 등록된 모든 쌍을 차례로 동기화합니다.
4. 삭제할 파일이 있으면 확인 창이 한 번 뜹니다. "예"를 누르면 삭제됩니다.

## 옵션

- **원본에서 삭제된 파일을 대상에서도 삭제**: 끄면 대상의 파일을 절대 지우지 않습니다(추가/변경만).
- **삭제 전 확인**: 끄면 확인 창 없이 바로 삭제합니다(자동화에 유용, 주의해서 사용).

등록한 폴더 쌍과 옵션은 자동으로 기억됩니다 (`사용자홈\.folder_sync_config.json`).

## 안전장치

- 대상 폴더가 원본 폴더 **안에** 있거나 그 반대인 경우, 무한 복사를 막기 위해 그 쌍을 건너뜁니다.
- 원본과 대상이 같은 폴더인 쌍은 건너뜁니다.
- 복사 시 `copy2`를 사용하여 파일의 수정시간 등 메타데이터를 보존합니다.

## 화면 / 배경

- 프로그램 창은 **정사각형(720 × 720)** 고정 크기입니다.
- 배경은 `assets/background.png` 그림(곰이 TV 보는 일러스트)을 사용합니다.
- **배경을 바꾸고 싶다면** 원하는 그림을 `720 × 720` 크기의 PNG로 만들어
  `assets/background.png` 를 덮어쓰면 됩니다. (그림의 위쪽 절반에 그림을 두고
  아래쪽은 단색으로 두면 컨트롤 패널과 잘 어울립니다.)
- 포함된 기본 배경은 `python tools/make_background.py` 로 다시 생성할 수 있습니다.

## 파일 구성

- `sync_app.py` — 프로그램 본체 (GUI + 동기화 로직)
- `assets/background.png` — 배경 이미지 (720×720)
- `tools/make_background.py` — 기본 배경 이미지 생성 스크립트
- `동기화_실행.bat` — Windows에서 Python으로 더블클릭 실행
- `build_exe.bat` — 단일 `.exe` 빌드 (PyInstaller, 배경 이미지 포함)
- `README.md` — 이 설명서
