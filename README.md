# 폴더 동기화 프로그램 (SSD → D드라이브)

버튼 하나로 원본(SSD) 폴더의 파일을 대상(D드라이브) 폴더로 동기화하는 데스크톱 프로그램입니다.
Python 표준 라이브러리(tkinter)만 사용하므로 **추가 설치 없이** 동작합니다.

## 동작 방식

| 상황 | 동작 |
|------|------|
| 원본·대상 파일이 동일 (크기 + 수정시간 일치) | **건너뛰기** |
| 원본에만 있는 파일 | **복사 (추가)** |
| 양쪽에 있으나 내용이 다른 파일 | **덮어쓰기 (변경)** |
| 원본에서 삭제되어 대상에만 남은 파일 | **삭제 (사용자에게 확인 후)** |

> 단방향 동기화입니다. 원본의 상태를 대상에 그대로 반영합니다.

## 사용 방법 (Windows)

1. **Python 설치** (이미 있으면 생략)
   - https://www.python.org/downloads/ 에서 설치
   - 설치 시 **"Add Python to PATH"** 체크
   - tkinter는 Windows용 Python에 기본 포함되어 있습니다.

2. **프로그램 실행**
   - `동기화_실행.bat` 파일을 더블클릭
   - 또는 명령 프롬프트에서 `python sync_app.py`

3. **화면에서**
   - **원본 폴더(SSD)** 와 **대상 폴더(D드라이브)** 를 각각 "찾아보기"로 선택
   - (권장) **미리보기** 버튼으로 어떤 파일이 추가/변경/삭제될지 먼저 확인
   - **동기화 시작** 버튼 클릭
   - 삭제할 파일이 있으면 확인 창이 뜹니다. "예"를 누르면 삭제됩니다.

## 옵션

- **원본에서 삭제된 파일을 대상에서도 삭제**: 끄면 대상의 파일을 절대 지우지 않습니다(추가/변경만).
- **삭제 전 확인**: 끄면 확인 창 없이 바로 삭제합니다(자동화에 유용, 주의해서 사용).

마지막에 선택한 폴더와 옵션은 자동으로 기억됩니다 (`사용자홈\.folder_sync_config.json`).

## 안전장치

- 대상 폴더가 원본 폴더 **안에** 있으면 무한 복사를 막기 위해 실행을 거부합니다.
- 원본과 대상이 같은 폴더이면 실행을 거부합니다.
- 복사 시 `copy2`를 사용하여 파일의 수정시간 등 메타데이터를 보존합니다.

## 파일 구성
