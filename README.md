# 폴더 동기화 프로그램 (SSD → D드라이브)

버튼 하나로 **여러 폴더 쌍**을 한꺼번에 동기화하는 데스크톱 프로그램입니다.
Python 표준 라이브러리(tkinter)만 사용하므로 추가 설치 없이 동작하고, 원하면 단일
`.exe` 파일로 빌드할 수도 있습니다.

## 동작 방식

| 상황 | 동작 |
|------|------|
| 원본·대상 파일이 동일 (크기 + 수정시간 일치) | **건너뛰기** |
| 원본에만 있는 파일 | **복사 (추가)** |
| 양쪽에 있으나 내용이 다른 파일 | **덮어쓰기 (변경)** |
| 원본에서 삭제되어 대상에만 남은 파일 | **삭제 (사용자에게 확인 후)** |

> 각 폴더 쌍은 단방향 동기화입니다. 원본의 상태를 대상에 그대로 반영합니다.

## 실행 방법 (둘 중 하나)

### 방법 A. Python 으로 바로 실행
1. https://www.python.org/downloads/ 에서 Python 설치 (설치 시 **"Add Python to PATH"** 체크)
2. `동기화_실행.bat` 더블클릭 (또는 `python sync_app.py`)

### 방법 B. 단일 .exe 로 만들어서 실행 (Python 없이 배포 가능)
1. `build_exe.bat` 더블클릭 → PyInstaller가 자동 설치되고 빌드됩니다.
2. 완료되면 `dist\폴더동기화.exe` 가 생성됩니다. 이 파일만 있으면
   Python이 없는 PC에서도 더블클릭으로 실행됩니다.

   직접 명령으로 빌드하려면:
   ```
   pip install pyinstaller
   pyinstaller --onefile --windowed --name "폴더동기화" sync_app.py
   ```
   - `--onefile` : 하나의 exe로 묶기
   - `--windowed` : 검은 콘솔 창 없이 GUI만 표시

   > exe 빌드는 **Windows에서 직접** 하셔야 Windows용 exe가 나옵니다.

## 화면 구성 / 사용 방법

밝고 선명한 카드형 UI입니다. 각 버튼에 마우스를 올리면 기능 설명이 **말풍선(툴팁)** 으로 표시됩니다.

1. **폴더 선택 카드**: `원본 폴더`·`대상 폴더` 옆 **찾아보기** 로 폴더를 고른 뒤
   **＋ 목록에 추가**(오렌지) 를 누릅니다.
2. **동기화 폴더 목록**: 등록된 쌍이 보입니다. 항목을 **더블클릭** 하면 위 칸으로 불러와 수정할 수 있고,
   **선택 제거 / 전체 비우기** 로 지웁니다.
3. **옵션**:
   - **같은 이름의 파일이 대상에 있을 때**:
     `무조건 건너뛰기` 또는 `파일 용량 또는 수정일자가 다르면 덮어쓰기` 중 선택.
   - `원본에서 삭제된 파일도 삭제`, `삭제 전 확인` 체크.
4. **예약**: `예약 실행` 체크 + `반복`(N분) 또는 `매일`(HH:MM) 선택.
5. **미리보기** 로 변경 내용을 먼저 확인 → **전체 동기화 시작**(오렌지) 으로 실행.
   삭제할 파일이 있으면 확인 창이 한 번 뜹니다("삭제 전 확인"이 켜진 경우).
   - 동기화 중에는 진행률 막대 아래에 **진행률(%)·남은 시간(ETA)·(처리/전체)** 가 표시됩니다.
   - 빨간 **멈추기** 버튼으로 진행 중인 동기화를 중지할 수 있습니다(현재 파일까지 마무리 후 중단).

진행률 막대와 로그가 아래에 표시됩니다. 내용이 길면 마우스 휠로 스크롤됩니다.

## 예약 실행

- **예약 실행** 을 체크하면 프로그램이 켜져 있는 동안 자동으로 동기화합니다.
  - **반복**: 입력한 분(예: 60) 간격마다 실행
  - **매일**: 입력한 시각(예: `03:00`)에 하루 한 번 실행
- 무인(자동) 운영을 원하면 **삭제 전 확인** 을 꺼 두는 것이 좋습니다(켜져 있으면 확인 창에서 멈춤).
- 예약은 프로그램이 실행 중일 때만 동작합니다. PC 부팅 시 자동 실행하려면 Windows
  **작업 스케줄러**에 exe(또는 `동기화_실행.bat`)를 등록하세요.

등록한 폴더 쌍·옵션·예약 설정은 자동으로 기억됩니다 (`사용자홈\.folder_sync_config.json`).

## 화면 / 폰트

- 흰색 카드 + 오렌지 포인트의 밝고 선명한 플랫 디자인입니다.
- 모든 항목이 **세로 스크롤 없이 한 화면**에 들어오도록 글꼴·여백을 조정했습니다.
- **고해상도(High-DPI) 대응**: Windows에서 화면 배율(125%/150% 등)이 적용돼도 글자와
  버튼이 흐릿하게 확대되지 않고 또렷하게 표시됩니다.
- 글꼴은 **Pretendard** 를 사용합니다. 시스템에 설치되어 있지 않다면
  `assets/Pretendard-Regular.ttf` 파일을 넣어 두면 설치 없이 적용됩니다(Windows).
  파일이 없으면 시스템 기본 글꼴로 자동 대체됩니다.

## 안전장치

- 대상 폴더가 원본 폴더 **안에** 있거나 그 반대인 경우, 무한 복사를 막기 위해 그 쌍을 건너뜁니다.
- 원본과 대상이 같은 폴더인 쌍은 건너뜁니다.
- 복사 시 `copy2`를 사용하여 파일의 수정시간 등 메타데이터를 보존합니다.
- 동기화는 백그라운드 스레드에서 실행되어 진행 중에도 화면이 멈추지 않습니다.

## 파일 구성

- `sync_app.py` — 프로그램 본체 (GUI + 동기화 로직)
- `assets/` — (선택) `Pretendard-Regular.ttf` 등 글꼴 파일을 넣는 곳
- `동기화_실행.bat` — Windows에서 Python으로 더블클릭 실행
- `build_exe.bat` — 단일 `.exe` 빌드 (PyInstaller)
- `README.md` — 이 설명서
